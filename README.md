# Aurum Studio

A responsive creative studio portfolio with an illustrated hero and three concept projects. Built with Next.js, React, and CSS.

## Local development

Use Node.js 22.13 or later.

```sh
npm ci
npm run dev
```

Open [localhost:3000](http://localhost:3000).

`npm run build` exports the site to `out/`. Serve that directory with any static web server.
